
# Survey App

## Overview

- This is a Rails 7.1.2 application that allows users to create surveys and collect responses. Users can view analytics such as the percentage of "Yes" and "No" responses for each survey.

## Features

- Create, read and delete surveys.
- Respond to surveys with "Yes" or "No" answers.
- View real-time analytics (percentage of "Yes" and "No" responses).
- Pagination for surveys.

## Requirements

- Ruby version: 3.2.1
- Rails version: 7.1.2

## Install Dependencies

 - bundle install

## Set Up the Database

- rails db:setup 

## Running tests

- rspec ./spec

## Start the Application

- rails server
